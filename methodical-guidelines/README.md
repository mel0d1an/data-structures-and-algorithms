# Методические материалы

- [`students/`](students/README.md) — методические указания обучающимся: регламент выполнения и защиты работ, варианты, отработка пропусков, правила использования генеративного ИИ.
- [`teachers-assessment/`](teachers-assessment/README.md) — методические указания преподавателям по оцениванию: шкалы, рубрики, критерии ФОС, анти-чит, апелляции.
- [`teachers-resources/`](teachers-resources/README.md) — методические указания преподавателям по сопровождению материалов: структура репозитория, актуализация, кейс-чемпионат.
