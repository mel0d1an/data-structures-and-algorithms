# Наборы данных

Все наборы данных дисциплины — **синтетические** и генерируются локально скриптом [`scripts/generate_data.py`](../../scripts/generate_data.py) детерминированно по номеру варианта (seed `30 + вариант`). Реальные данные индустриальных партнёров в репозитории не используются (см. таблицу рисков в [`methodical-guidelines/teachers-resources/`](../../methodical-guidelines/teachers-resources/README.md)).

| Набор | Описание | Связанные КИМ |
| --- | --- | --- |
| Массивы целых чисел | случайные / отсортированные / обратно отсортированные / с дубликатами, размеры 10³–10⁵ | ЛР 1, 3, 4, 6 |
| Тексты и шаблоны | псевдослучайные тексты над малым алфавитом + шаблоны с гарантированными вхождениями | ЛР 7 |
| Пары «ключ–значение» | строковые ключи с управляемой частотой коллизий | ЛР 8 |
| Журнал событий ОС | синтетический лог (процессы, события, метки времени) с внедрёнными аномальными последовательностями | ДЗ 3 (кейс ГК «Астра») |
| Псевдо-эмбеддинги документов | векторы малой размерности с кластерной структурой (пары «резюме–вакансия») | ДЗ 4 (кейс hh.ru) |

Генерация: `python scripts/generate_data.py --variant N` (файлы попадают в `data/generated/` и не коммитятся).
