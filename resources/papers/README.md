# Статьи и классические источники

Необязательные материалы для углублённого изучения (СР, доклады, кейс-чемпионат):

| Источник | Тема | Связанные КИМ |
| --- | --- | --- |
| Knuth D. The Art of Computer Programming, Vol. 3: Sorting and Searching | сортировки, поиск | ЛР 3–6 |
| Cormen T., Leiserson C., Rivest R., Stein C. Introduction to Algorithms (4th ed., MIT Press, 2022) | весь курс | все |
| Knuth D., Morris J., Pratt V. Fast Pattern Matching in Strings // SIAM J. Comput. 6(2), 1977 | КМП | ЛР 7 |
| Karp R., Rabin M. Efficient randomized pattern-matching algorithms // IBM J. Res. Dev. 31(2), 1987 | Рабин–Карп | ЛР 7 |
| Boyer R., Moore J. A Fast String Searching Algorithm // CACM 20(10), 1977 | Бойер–Мур | ЛР 7 |
| Indyk P., Motwani R. Approximate Nearest Neighbors: Towards Removing the Curse of Dimensionality // STOC 1998 | LSH, поиск ближайших соседей | ДЗ 4 |

Доступ к статьям — через научные библиотеки и [eLibrary](https://www.elibrary.ru/defaultx.asp); карточка добавляемого ресурса должна содержать аннотацию, связанные КИМ и дату проверки ссылки.
