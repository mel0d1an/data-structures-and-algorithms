# Ресурсы дисциплины

Каталоги с карточками ресурсов (аннотация, связанные КИМ, доступ, дата проверки):

- [`textbooks/`](textbooks/README.md) — основная и дополнительная литература, ЭБС.
- [`software/`](software/README.md) — среды разработки, линтеры, система контроля версий.
- [`datasets/`](datasets/README.md) — синтетические наборы данных для ЛР и ДЗ.
- [`test-banks/`](test-banks/README.md) — промежуточные тестирования № 1–4, вопросы к зачёту и защитам.
- [`problem-banks/`](problem-banks/README.md) — банки практических задач и контрольные вопросы для СР.
- [`llm-prompts/`](llm-prompts/README.md) — правила и примеры промптов для работы с БЯМ.
- [`papers/`](papers/README.md) — статьи и классические источники по алгоритмам.
- [`other/`](other/README.md) — прочие материалы.
