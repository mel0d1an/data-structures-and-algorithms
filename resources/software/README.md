# Программное обеспечение

По перечню РПД (лицензионное и свободно распространяемое, в том числе отечественного производства):

| ПО | Назначение | Связанные КИМ |
| --- | --- | --- |
| Python 3.10+ | основной язык лабораторного практикума | все |
| PyCharm | среда разработки | все |
| VS Code | среда разработки | все |
| AstraGitFlic (GitFlic) | система контроля версий; сдача работ | все (критерий ОПК-6.4) |
| black, pylint | автоформатирование и линтинг Python | все (критерий ОПК-6.3) |
| clang-format | форматирование для выполняющих работы на C/C++ | по согласованию |
| matplotlib | графики бенчмарков | ЛР 1, 3–6, ДЗ 2–4 |

Языки C/C++/Java допускаются по согласованию с преподавателем; требования к оформлению — соответствующие стандартные стили (Google C++ Style, Oracle Java Conventions).

Окружение Python устанавливается по [`requirements.txt`](../../requirements.txt); настройка — [`docs/reproducibility.md`](../../docs/reproducibility.md).
