# Банки вопросов промежуточных тестирований № 1–4

Четыре теста по разделам 1–4 тематического плана; в каждом 10 вопросов с выбором одного ответа из четырёх (А–Г). Регламент проведения — в [`README.md`](README.md); ключи с пояснениями — материал преподавателя, хранится в закрытом хранилище кафедры. Банк примерный: перед проведением преподаватель перемешивает вопросы и варианты ответов и при необходимости заменяет числовые данные.

## Тест 1. Базовые принципы алгоритмизации и оценка сложности

**1.** Что означает обозначение O(n log n) в контексте алгоритма?

- А) Линейная сложность
- Б) Полиномиальная сложность
- В) Логарифмическая сложность
- Г) Сложность, растущая быстрее линейной, но медленнее квадратичной

**2.** Что из перечисленного является характеристикой жёсткой детерминированности алгоритма?

- А) Всегда одно и то же время выполнения
- Б) Наличие циклов
- В) Повторяемость результата при одних и тех же входных данных
- Г) Использование рекурсии

**3.** Запись f(n) = Ω(g(n)) означает, что:

- А) f растёт не быстрее g
- Б) f растёт не медленнее g (с точностью до константного множителя)
- В) f и g растут одинаково
- Г) f растёт строго быстрее g

**4.** Какая нотация задаёт одновременно верхнюю и нижнюю асимптотические границы?

- А) Θ
- Б) O
- В) Ω
- Г) o

**5.** Какую оценку даёт мастер-теорема для рекурренты T(n) = 2T(n/2) + O(n)?

- А) O(n)
- Б) O(n²)
- В) O(n log n)
- Г) O(log n)

**6.** Какому рекуррентному соотношению соответствует бинарный поиск?

- А) T(n) = T(n/2) + O(1)
- Б) T(n) = 2T(n/2) + O(n)
- В) T(n) = T(n − 1) + O(1)
- Г) T(n) = 2T(n − 1) + O(1)

**7.** Какова амортизированная сложность добавления элемента в конец динамического массива с удвоением ёмкости?

- А) O(log n)
- Б) O(n)
- В) O(n log n)
- Г) O(1)

**8.** Какая структура данных работает по принципу LIFO («последним пришёл — первым ушёл»)?

- А) Очередь
- Б) Стек
- В) Дек
- Г) Связный список

**9.** Что позволяет делать дек в отличие от очереди?

- А) Добавлять и удалять элементы с обоих концов
- Б) Хранить элементы разных типов
- В) Обращаться к элементу по индексу за O(1)
- Г) Автоматически сортировать элементы

**10.** Какое свойство алгоритма гарантирует, что он завершается за конечное число шагов?

- А) Дискретность
- Б) Массовость
- В) Детерминированность
- Г) Результативность (конечность)

## Тест 2. Алгоритмы сортировки

**1.** Какова худшая временная сложность сортировки пузырьком?

- А) O(n)
- Б) O(n log n)
- В) O(n²)
- Г) O(log n)

**2.** Какой из перечисленных алгоритмов всегда стабилен?

- А) QuickSort
- Б) HeapSort
- В) MergeSort
- Г) RadixSort

**3.** Какова средняя временная сложность QuickSort?

- А) O(n log n)
- Б) O(n²)
- В) O(n)
- Г) O(log n)

**4.** На каком входе QuickSort с выбором первого элемента в качестве опорного показывает худший случай O(n²)?

- А) На массиве случайных чисел
- Б) На уже отсортированном массиве
- В) На массиве из одного элемента
- Г) На массиве чётной длины

**5.** Что даёт рандомизированный выбор опорного элемента в QuickSort?

- А) Гарантирует худший случай O(n log n)
- Б) Делает сортировку стабильной
- В) Уменьшает дополнительную память до O(1)
- Г) Делает худший случай маловероятным на любом фиксированном входе

**6.** Какое условие критично для эффективности сортировки подсчётом (CountingSort)?

- А) Массив почти отсортирован
- Б) Диапазон значений ключей k невелик и сопоставим с n
- В) Все элементы различны
- Г) Массив помещается в кэш процессора

**7.** Почему поразрядная сортировка (LSD RadixSort) требует устойчивой сортировки внутри каждого разряда?

- А) Иначе нарушится порядок, установленный сортировкой по предыдущим разрядам
- Б) Иначе сложность станет квадратичной
- В) Для экономии памяти
- Г) Для работы с отрицательными числами

**8.** Каковы временная сложность HeapSort в худшем случае и его дополнительная память?

- А) O(n²) и O(n)
- Б) O(n log n) и O(n)
- В) O(n log n) и O(1)
- Г) O(n) и O(1)

**9.** Какова нижняя граница числа сравнений для сортировок, основанных на сравнениях?

- А) Ω(n)
- Б) Ω(n²)
- В) Ω(log n)
- Г) Ω(n log n)

**10.** На каком входе сортировка вставками работает за O(n)?

- А) На почти отсортированном массиве
- Б) На массиве, отсортированном в обратном порядке
- В) На массиве случайных чисел
- Г) Ни на каком — её сложность всегда O(n²)

## Тест 3. Структуры на деревьях

**1.** Что такое AVL-дерево?

- А) Любое двоичное дерево
- Б) Самобалансирующееся дерево поиска
- В) Дерево с фиксированной глубиной
- Г) Граф без циклов

**2.** Какой из обходов дерева соответствует порядку: левый — корень — правый?

- А) Pre-order
- Б) Post-order
- В) In-order
- Г) Level-order

**3.** Какой инвариант выполняется в бинарном дереве поиска (BST)?

- А) Ключи левого поддерева меньше ключа узла, ключи правого — больше
- Б) Дерево всегда сбалансировано
- В) Каждый узел имеет ровно двух детей
- Г) Высоты левого и правого поддеревьев различаются не более чем на 1

**4.** Что возвращает in-order обход корректного BST?

- А) Ключи в порядке вставки
- Б) Ключи в порядке убывания
- В) Ключи по уровням дерева
- Г) Ключи в порядке возрастания

**5.** Каким узлом при удалении заменяется узел BST с двумя детьми?

- А) Корнем дерева
- Б) Минимальным узлом правого поддерева (преемником)
- В) Произвольным листом
- Г) Всегда левым ребёнком

**6.** Какова высота AVL-дерева с n узлами?

- А) Θ(n)
- Б) Θ(√n)
- В) Θ(log n)
- Г) Θ(n log n)

**7.** Во что вырождается BST без балансировки при вставке ключей в порядке возрастания?

- А) В структуру, эквивалентную связному списку, с операциями за O(n)
- Б) В полное двоичное дерево
- В) В хеш-таблицу
- Г) Остаётся сбалансированным, операции за O(log n)

**8.** Какова сложность поиска в BST без балансировки в худшем случае?

- А) O(1)
- Б) O(log n)
- В) O(n log n)
- Г) O(n)

**9.** Какой обход применяется, когда узел нужно обработать после обоих его поддеревьев (например, при освобождении памяти дерева)?

- А) Pre-order
- Б) Post-order
- В) In-order
- Г) Level-order

**10.** Что выполняет AVL-дерево при нарушении баланса после вставки?

- А) Полную перестройку дерева
- Б) Рехеширование узлов
- В) Удаление нарушившего баланс узла
- Г) Одиночные или двойные повороты вокруг разбалансированных узлов

## Тест 4. Эффективный поиск и хеширование

**1.** Какова средняя сложность поиска в хеш-таблице с хорошей хеш-функцией?

- А) O(n)
- Б) O(log n)
- В) O(1)
- Г) O(n log n)

**2.** При каком условии бинарный поиск работает корректно?

- А) Массив должен быть отсортирован
- Б) Элементы массива уникальны
- В) Все элементы положительные
- Г) Используется только линейная память

**3.** Какова средняя сложность интерполяционного поиска на равномерно распределённых данных?

- А) O(log n)
- Б) O(log log n)
- В) O(n)
- Г) O(1)

**4.** Что хранит префикс-функция π[i] в алгоритме Кнута–Морриса–Пратта?

- А) Индекс первого вхождения символа в шаблон
- Б) Хеш префикса длины i
- В) Число различных символов в префиксе длины i
- Г) Длину наибольшего собственного суффикса префикса s[0..i], совпадающего с его префиксом

**5.** Зачем в алгоритме Рабина–Карпа выполняется посимвольная проверка при совпадении хешей?

- А) Для ускорения поиска
- Б) Для пересчёта скользящего хеша
- В) Из-за возможных коллизий хешей (ложных срабатываний)
- Г) Для поддержки больших алфавитов

**6.** На чём основана эвристика «плохого символа» в алгоритме Бойера–Мура?

- А) На сдвиге шаблона так, чтобы несовпавший символ текста совместился с его ближайшим вхождением в шаблон
- Б) На хешировании окна текста
- В) На построении префикс-функции шаблона
- Г) На последовательном переборе всех позиций текста

**7.** Что такое коэффициент загрузки α хеш-таблицы?

- А) Число произошедших коллизий
- Б) Отношение числа хранимых элементов к числу корзин
- В) Длина максимальной цепочки
- Г) Размер таблицы в байтах

**8.** Чем метод цепочек отличается от открытой адресации?

- А) Цепочки не требуют хеш-функции
- Б) Открытая адресация быстрее в худшем случае
- В) Открытая адресация не разрешает коллизии
- Г) При коллизии цепочки хранят элементы во внешних списках, а открытая адресация ищет свободную ячейку в самой таблице

**9.** Что обычно выполняется при превышении порогового коэффициента загрузки хеш-таблицы?

- А) Удаление самых старых элементов
- Б) Переход на линейный поиск
- В) Увеличение числа корзин и перехеширование всех элементов
- Г) Сортировка цепочек по ключу

**10.** Почему при поиске ближайших соседей по эмбеддингам документов (например, при подборе вакансий к резюме — см. ДЗ 4) точный перебор заменяют приближёнными индексами (ANN)?

- А) Точный перебор требует O(n·d) операций на запрос и не масштабируется на миллионы векторов
- Б) Точный перебор возвращает неверных соседей
- В) Векторные представления нельзя сравнивать напрямую
- Г) Приближённые методы всегда дают более точный результат
