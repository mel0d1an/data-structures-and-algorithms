# Банки тестов и вопросов

Каталог содержит банки оценочных материалов дисциплины: вопросы промежуточных тестирований № 1–4, перечень вопросов и практических задач к зачёту, вопросы к защитам лабораторных работ.

## Назначение

Банки обеспечивают три формы контроля:

- **промежуточные тестирования № 1–4** — текущий контроль усвоения теории по разделам 1–4;
- **зачёт** — промежуточная аттестация семестра (см. [`Exam/`](../../Exam/README.md));
- **защиты ЛР 1–8** — устная часть текущего контроля по лабораторным работам.

## Регламент промежуточных тестирований № 1–4

| Параметр | Значение |
| --- | --- |
| Периодичность | По завершении каждого из разделов 1–4 тематического плана |
| Объём | ~10 вопросов с выбором одного ответа из четырёх (А–Г) |
| Время | ~15 минут |
| Оценивание | До **4 баллов БРС** за тестирование (0,4 балла за верный ответ, суммарно до 16 баллов за семестр) |
| Форма | Письменно или в LMS, по решению преподавателя; без внешних ресурсов и ИИ-инструментов |

| Тестирование | Раздел | Тема |
| --- | --- | --- |
| № 1 | Раздел 1 | Базовые принципы алгоритмизации и оценка сложности |
| № 2 | Раздел 2 | Алгоритмы сортировки |
| № 3 | Раздел 3 | Структуры на деревьях |
| № 4 | Раздел 4 | Эффективный поиск и хеширование |

Связь тестирований с итоговой оценкой — в [`README.md`](../../README.md#4-итоговая-оценка) репозитория.

## Примечание

Банки являются **примерными и расширяемыми**: они задают тематический охват и уровень сложности, но не ограничивают преподавателя. Актуальные варианты тестирований и зачётного теста формирует преподаватель перед каждым проведением (перестановка вопросов и вариантов ответов, замена числовых данных, добавление новых вопросов по темам банка). Вопросы о верификации ИИ-решений опираются на сквозную методику [`docs/ai-verification.md`](../../docs/ai-verification.md).
