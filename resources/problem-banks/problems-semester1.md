# Банк задач. Семестр 1

Пять наборов задач по темам семестра 1 (разделы 1–4 тематического плана, см. [`docs/rpd.md`](../../docs/rpd.md)). Назначение и порядок использования — в [`README.md`](README.md).

Пометка **(ФОС)** означает, что задача входит в ФОС дисциплины и воспроизводится дословно; остальные задачи — дополнительные, того же стиля и уровня. Ответ на каждую задачу — краткое письменное решение с обоснованием; программная реализация приветствуется, но не обязательна, если в задаче не указано иное.

## Набор 1. Модели данных, алгоритмы и методы оценки сложности

1. **(ФОС)** Определите временную сложность алгоритма, который для каждого элемента массива находит сумму всех последующих элементов. Объясните свой выбор.
2. **(ФОС, опережающее задание к разделу 5 второго семестра «Жадные алгоритмы и динамическое программирование»)** Приведите пример задачи, решаемой жадным методом, и обоснуйте, почему для неё он применим. Сравните с аналогичной задачей, где такой подход не работает.
3. Расположите функции log₂ n, √n, n, n·log₂ n, n², 2ⁿ в порядке возрастания скорости роста. Обоснуйте попарные сравнения соседних функций через пределы или подстановку больших n.
4. Алгоритм A выполняет 3n² + 20n элементарных операций, алгоритм B — 500·n·log₂ n. Определите, начиная с каких n алгоритм B становится выгоднее, и объясните, почему константы и младшие члены не отражаются в асимптотической записи.
5. Составьте рекуррентное соотношение для времени работы рекурсивной функции, которая делит массив пополам, обрабатывает обе половины и выполняет линейное по длине массива слияние результатов. Решите соотношение с помощью мастер-теоремы.

## Набор 2. Базовые структуры данных

1. **(ФОС)** Опишите структуру данных, подходящую для реализации очереди с приоритетом, и объясните её основные операции.
2. **(ФОС)** Назовите и охарактеризуйте различия между динамическим массивом и связным списком. В каких случаях предпочтительнее использовать каждую из структур?
3. Опишите реализацию очереди на двух стеках. Оцените амортизированную сложность операций enqueue и dequeue и объясните, почему отдельная операция может стоить O(n).
4. Объясните, почему добавление элемента в конец динамического массива имеет амортизированную сложность O(1), хотя отдельная вставка при расширении буфера стоит O(n). Как на оценку влияет коэффициент роста ёмкости?
5. Предложите структуру данных для проверки сбалансированности скобочной последовательности из скобок трёх видов и опишите алгоритм её использования с оценкой сложности.

## Набор 3. Алгоритмы сортировки

1. **(ФОС)** Сравните сортировки вставками, выбором и пузырьком по числу сравнений и перестановок на разных типах входных данных (упорядоченных, случайных, обратно отсортированных).
2. **(ФОС)** Приведите пример задачи, где использование быстрой сортировки может привести к её худшему времени выполнения. Объясните, как это можно предотвратить.
3. Определите, какие из изученных сортировок стабильны. Приведите пример входных данных — записей с двумя полями, — на которых нестабильность алгоритма меняет итоговый порядок при сортировке по одному ключу.
4. Обоснуйте выбор алгоритма сортировки для массива из миллиона целых чисел в диапазоне 0…1000. Сравните с ситуацией, когда диапазон ключей заранее неизвестен и может быть сколь угодно велик.
5. Сравните сортировку слиянием и кучную сортировку по асимптотике, дополнительной памяти и стабильности. В каких сценариях каждая из них предпочтительнее?

## Набор 4. Алгоритмы поиска и структуры деревьев

1. **(ФОС)** Сформируйте дерево поиска по заданной последовательности чисел. Укажите порядок обхода in-order и опишите его особенности.
2. **(ФОС)** Сравните производительность линейного, бинарного и интерполяционного поиска при различных распределениях данных. В каких случаях каждый из них предпочтительнее?
3. Покажите на примере, как порядок вставки одних и тех же ключей влияет на высоту бинарного дерева поиска. Какая последовательность вставок даёт вырожденное дерево и к какой сложности поиска это приводит?
4. Опишите удаление из бинарного дерева поиска узла с двумя потомками. Объясните, почему узел заменяется преемником (минимумом правого поддерева) и как при этом сохраняется свойство дерева поиска.
5. Объясните, как поддерживается баланс в АВЛ-дереве при вставке. Приведите последовательность ключей, при которой требуется двойной поворот, и выполните его пошагово.

## Набор 5. Поиск подстрок и хеширование

1. **(ФОС)** Объясните принцип построения таблицы префиксов в алгоритме Кнута–Морриса–Пратта. Почему этот алгоритм эффективнее на длинных шаблонах?
2. **(ФОС)** Опишите работу хеш-таблицы с использованием метода цепочек. Что происходит при увеличении коэффициента заполнения?
3. Опишите алгоритм Рабина–Карпа. За счёт чего полиномиальный хеш окна пересчитывается за O(1) при сдвиге на один символ и когда возникают ложные срабатывания?
4. Сравните разрешение коллизий методом цепочек и открытой адресацией с линейным пробированием по расходу памяти и поведению операций при росте коэффициента заполнения.
5. Предложите хеш-функцию для строк и объясните, какие её свойства влияют на равномерность распределения ключей по корзинам. Приведите пример неудачной хеш-функции и покажите, на каких данных она деградирует.
