# Работа с большими языковыми моделями

Правила дисциплины: генеративный ИИ — вспомогательный инструмент; любое сгенерированное решение верифицируется по методике [`docs/ai-verification.md`](../../docs/ai-verification.md), а на защите объясняется самим обучающимся. Конфиденциальные материалы (в т.ч. кейсов партнёров) во внешние сервисы не передаются.

## Примеры корректных промптов

**Пояснение материала:**
> Объясни, почему амортизированная сложность push_back динамического массива равна O(1), хотя отдельная операция может стоить O(n). Приведи расчёт методом бухгалтерского учёта.

**Генерация тестов (а не решения):**
> Составь набор из 10 репрезентативных тестов для функции сортировки списка целых чисел: граничные, вырожденные и случайные случаи. Для каждого теста укажи, какой класс входов он покрывает.

**Ревью собственного кода:**
> Вот моя реализация бинарного поиска [код]. Не решай задачу заново: укажи, на каких классах входов она может ошибаться, и предложи, какие инварианты стоит проверить assert-ами.

**Проверка ИИ-кода (ДЗ 1):**
> Оцени асимптотическую сложность этой функции по шагам, не запуская её. Есть ли входы, на которых она деградирует до худшего случая?

## Некорректное использование

- «Реши лабораторную работу №N за меня» — сдача такого решения без верификации и понимания = 0 баллов по критериям верификации и понимания на защите.
- Передача в БЯМ текстов заданий с пометкой о конфиденциальности или данных партнёров.
