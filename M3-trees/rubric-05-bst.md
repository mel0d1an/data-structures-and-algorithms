# Рубрика-05. ЛР 5 «Построение бинарного дерева поиска и реализация обходов; вставка и удаление элементов»

10-балльная шкала оценивания. Балл рубрики входит в БРС с коэффициентом 0,6 (до 6 баллов за ЛР). Общие правила оценивания — в [`methodical-guidelines/teachers-assessment/`](../methodical-guidelines/teachers-assessment/README.md).

| Уровень | Описание |
| --- | --- |
| **10** | `insert`, `search` и `delete` корректны, включая все три случая удаления; четыре обхода и высота реализованы верно; инвариант BST проверен через in-order, операции сверены с эталоном `set`/`sorted` на случайных командах; сравнение поиска в BST и списке выполнено по методике (прогрев, повторы, медиана); в отчёте асимптотика выражена через высоту, деградация на упорядоченных данных и гарантия AVL (1,44·log₂(n)) объяснены; студент уверенно разбирает удаление узла с двумя детьми. |
| **8** | Всё выполнено; мелкие недочёты (например, преемник ищется неоптимально, level-order сделан без очереди или сверка с эталоном покрывает не все операции) студент находит и исправляет сам; объяснение уверенное. |
| **6** | Вставка, поиск и обходы работают, но `delete` реализован не для всех случаев либо верификация ограничена ручными примерами без сверки с эталоном; замеры есть, но связь асимптотики с формой дерева объяснена поверхностно. |
| **4** | Удаление отсутствует или ломает инвариант BST; часть обходов не реализована; сравнение с списком не проведено или выводы не связаны с данными; работает только по образцу. |
| **0–3** | Код не работает, инвариант BST не проверяется или студент не может объяснить собственное решение. |

## Критерии (вклад в итоговый балл)

| Критерий | Доля |
| --- | --- |
| Корректность реализации (insert/search/delete со всеми случаями, обходы, высота, инвариант BST) | 35 % |
| Вычислительная эффективность (оценки через высоту дерева, соответствие замеров BST/список теории) | 25 % |
| Полнота верификации (in-order-проверка, сверка с эталоном `set`/`sorted`, проверка ИИ-кода по методике при его использовании) | 20 % |
| Качество и оформление кода (читаемость, PEP-8, работа с системой версий) | 10 % |
| Обоснованность выводов (зависимость сложности от формы дерева, мостик к AVL и ДЗ 2) | 10 % |

## Связь с БРС

Итоговый балл за ЛР (0–10) переводится в БРС с коэффициентом 0,6 и суммируется с баллами за остальные ЛР (максимум 48), тестирования (16), дополнительные практические задания (10) и зачёт (30) — см. [`README.md`](../README.md#4-итоговая-оценка).
