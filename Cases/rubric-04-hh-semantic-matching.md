# Рубрика-04. ДЗ 4 «Семантический подбор резюме и вакансий по векторным представлениям»

10-балльная шкала оценивания. Балл рубрики входит в БРС с коэффициентом 0,3 (до 3 баллов за ДЗ 4). Общие правила оценивания — в [`methodical-guidelines/teachers-assessment/`](../methodical-guidelines/teachers-assessment/README.md).

| Уровень | Описание |
| --- | --- |
| **10** | Точный поиск реализован корректно и подтверждён на эталонных соответствиях; LSH-бакетизация работает на собственной хеш-таблице с цепочками; эксперимент проведён по методике (прогрев, повторы, медиана) не менее чем для трёх значений m; recall@k вычислен верно; асимптотика обоих подходов выведена и согласована с замерами; компромисс «скорость — полнота» и вывод о применимости обоснованы собственными результатами; обзорный абзац о промышленных решениях (инвертированные индексы, HNSW) содержателен; студент уверенно отвечает на вопросы. |
| **8** | Всё выполнено; мелкие недочёты (например, узкий диапазон m, неполный анализ зависимости recall@k от m или неполное объяснение связи подписи с косинусной близостью) студент находит и исправляет сам; объяснение уверенное. |
| **6** | Точный поиск корректен, но приближённая часть выполнена частично: бакеты хранятся в готовом контейнере вместо собственной хеш-таблицы, взято одно значение m либо замеры проведены без методики; recall@k посчитан, но интерпретирован поверхностно; асимптотика дана без обоснования. |
| **4** | Реализован только точный поиск, либо LSH не даёт осмысленных результатов (recall@k не вычислен или вычислен неверно); сравнение подходов и обзорный абзац отсутствуют; выводы не связаны с данными; работает только по образцу. |
| **0–3** | Код не работает, сверка приближённого поиска с точным отсутствует, либо студент не может объяснить собственное решение и полученные значения recall@k. |

## Критерии (вклад в итоговый балл)

| Критерий | Доля |
| --- | --- |
| Корректность реализации (точный поиск подтверждён эталонными соответствиями и тестами; LSH-подпись и собственная хеш-таблица бакетов работают верно) | 30 % |
| Вычислительная эффективность (аналитические оценки сложности обоих подходов, бенчмарк по методике, фактическое ускорение LSH относительно линейного скана) | 25 % |
| Полнота верификации (сверка приближённого поиска с точным, корректный recall@k, граничные случаи, проверка ИИ-кода по методике при его использовании) | 20 % |
| Качество и оформление кода (читаемость, PEP-8, работа с системой версий) | 10 % |
| Обоснованность выводов (интерпретация компромисса «скорость — полнота», влияние m, вывод о применимости, обзор промышленных решений) | 15 % |

## Связь с БРС

Итоговый балл за ДЗ (0–10) переводится в БРС с коэффициентом 0,3 (до 3 баллов) и суммируется с баллами за остальные дополнительные практические задания (всего до 10), лабораторные работы (48), тестирования (16) и зачёт (30) — см. [`README.md`](../README.md#4-итоговая-оценка).
