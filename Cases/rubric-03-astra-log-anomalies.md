# Рубрика-03. ДЗ 3 «Обнаружение аномалий в журналах событий ОС» (кейс ГК «Астра»)

10-балльная шкала оценивания. Балл рубрики входит в БРС с коэффициентом 0,3 (до 3 баллов за ДЗ 3).

| Уровень | Описание |
| --- | --- |
| **10** | Все три механизма детектирования реализованы корректно и эффективно: частоты — на собственной хеш-таблице с амортизированным O(1) на операцию, всплески — за один проход окном методом двух указателей, сигнатуры — КМП или Бойером–Муром с обоснованием выбора и учётом перекрывающихся вхождений; сложность этапов выведена и подтверждена замерами по методике на журналах разного размера; детектор верифицирован по файлу-ответу, точность и полнота вычислены и содержательно проинтерпретированы; студент уверенно отвечает на вопросы. |
| **8** | Всё выполнено; мелкие недочёты (например, неполный ряд размеров журнала, неучтённые перекрывающиеся вхождения или неполная интерпретация точности/полноты) студент находит и исправляет сам; объяснение уверенное. |
| **6** | Детектор в целом находит аномалии, но один из этапов реализован неэффективно или без обоснования (например, окно наивно пересчитывается для каждой позиции, выбор алгоритма поиска подстрок не аргументирован) либо верификация по файлу-ответу выполнена частично (метрики вычислены без интерпретации); объяснение поверхностное. |
| **4** | Часть этапов отсутствует или неверна (например, частоты считаются встроенным `dict` вместо собственной хеш-таблицы, всплески или сигнатуры не обнаруживаются); точность и полнота не вычислены; выводы не связаны с данными; работает только по образцу. |
| **0–3** | Код не работает, аномалии не обнаруживаются, детектор подогнан под файл-ответ или студент не может объяснить собственное решение. |

## Критерии (вклад в итоговый балл)

| Критерий | Доля |
| --- | --- |
| Корректность реализации (хеш-таблица, скользящее окно, поиск сигнатур; совпадение с эталонными сверками) | 30 % |
| Вычислительная эффективность (обоснованность оценок сложности этапов, соответствие замеров асимптотике) | 25 % |
| Полнота верификации (точность и полнота по файлу-ответу, граничные случаи, проверка ИИ-кода по методике при его использовании) | 20 % |
| Качество и оформление кода (читаемость, PEP-8, работа с системой версий) | 10 % |
| Обоснованность выводов (интерпретация найденных аномалий и метрик, аргументация выбора алгоритмов) | 15 % |

## Связь с БРС

Итоговый балл за ДЗ (0–10) переводится в БРС с коэффициентом 0,3 (до 3 баллов) и суммируется с баллами за лабораторные работы (максимум 48), тестирования (16), остальные дополнительные практические задания и зачёт (30) — см. [`README.md`](../README.md#4-итоговая-оценка).
