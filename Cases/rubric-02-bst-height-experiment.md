# Рубрика-02. ДЗ 2 «Эксперимент: высота BST и деградация операций»

10-балльная шкала оценивания. Балл рубрики входит в БРС с коэффициентом 0,2 (до 2 баллов за ДЗ). Общие правила оценивания — в [`methodical-guidelines/teachers-assessment/`](../methodical-guidelines/teachers-assessment/README.md).

| Уровень | Описание |
| --- | --- |
| **10** | Эксперимент поставлен корректно: высота и средняя глубина измерены на случайном и упорядоченном потоках (≥5 размеров, n до 10⁴, итеративная вставка для упорядоченного потока); графики h(n) построены на фоне log₂(n) и n и интерпретированы верно; деградация до O(n) объяснена через форму дерева; теоретическая справка об AVL (гарантия 1,44·log₂(n), цена балансировки) полна; вывод-рекомендация обоснован данными; измерительные функции верифицированы (граничные деревья, аналитические значения, сверка с `sorted()`); студент уверенно отвечает на вопросы. |
| **8** | Всё выполнено; мелкие недочёты (например, неполный ряд размеров, отсутствие опорной кривой n на графике или неполная справка о цене балансировки) студент находит и исправляет сам; объяснение деградации уверенное. |
| **6** | Замеры и графики в целом верны, но упорядоченный поток исследован не полностью (малые n, рекурсивная вставка) либо теоретическая справка дана без обоснования гарантии AVL; вывод-рекомендация формален, объяснение поверхностное. |
| **4** | Измерен только один из потоков, графики отсутствуют или не сопоставлены с опорными кривыми; деградация констатирована без объяснения; вывод не связан с данными; работает только по образцу. |
| **0–3** | Код не работает, замеры отсутствуют или студент не может объяснить собственный эксперимент. |

## Критерии (вклад в итоговый балл)

| Критерий | Доля |
| --- | --- |
| Корректность реализации (измерение высоты и средней глубины, итеративная вставка, генерация потоков по варианту) | 30 % |
| Вычислительная эффективность (полнота ряда размеров, корректное сопоставление h(n) с log₂(n) и n, связь высоты с асимптотикой операций) | 25 % |
| Полнота верификации (граничные деревья, аналитические значения вырожденного дерева, сверка in-order с `sorted()`, проверка ИИ-кода по методике при его использовании) | 20 % |
| Качество и оформление кода (читаемость, PEP-8, воспроизводимость по seed, работа с системой версий) | 10 % |
| Обоснованность выводов (объяснение деградации, теоретическая справка об AVL, вывод-рекомендация о выборе структуры) | 15 % |

## Связь с БРС
