# Рубрика-02. ЛР 2 «Реализация рекурсивных функций и динамического массива, стека и дека»

10-балльная шкала оценивания. Балл рубрики входит в БРС с коэффициентом 0,6 (до 6 баллов за ЛР). Общие правила оценивания — в [`methodical-guidelines/teachers-assessment/`](../methodical-guidelines/teachers-assessment/README.md).

| Уровень | Описание |
| --- | --- |
| **10** | Все рекурсивные функции корректны: выигрыш мемоизации подтверждён счётчиком вызовов, число перемещений Ханойских башен совпадает с 2^n − 1; `DynamicArray` с ростом ×2 держит инвариант size ≤ capacity, `Stack` и `Deque` проходят тесты LIFO/FIFO, включая границу роста ёмкости; средняя стоимость `append` замерена и интерпретирована как амортизированная O(1); сравнение с `list` и `collections.deque` (вставка в начало) объяснено; анализ методом учёта проведён корректно; студент уверенно отвечает на вопросы. |
| **8** | Всё выполнено; мелкие недочёты (например, счётчик вызовов сравнён лишь на одном n, неполный анализ методом учёта или пропущенный граничный тест на границе роста ёмкости) студент находит и исправляет сам; объяснение уверенное. |
| **6** | Рекурсивные функции и структуры в целом работают, но замер стоимости `append` выполнен с нарушением методики либо амортизированная оценка и сравнение с `list`/`deque` даны без обоснования; инварианты проверены частично; объяснение поверхностное. |
| **4** | Часть функций или структур отсутствует/неверна (например, дек не поддерживает операции с одного из концов или рост ёмкости реализован пересозданием на каждый `append`); выводы не связаны с замерами; работает только по образцу. |
| **0–3** | Код не работает, замеры отсутствуют или студент не может объяснить собственное решение. |

## Критерии (вклад в итоговый балл)

| Критерий | Доля |
| --- | --- |
| Корректность реализации (рекурсивные функции, `DynamicArray`, `Stack`, `Deque`; прохождение репрезентативных тестов, инварианты) | 35 % |
| Вычислительная эффективность (рост ёмкости ×2, амортизированная O(1) для `append`, обоснованность оценок рекурсии) | 25 % |
| Полнота верификации (граничные случаи, сверка с эталонами стандартной библиотеки, проверка ИИ-кода по методике при его использовании) | 20 % |
| Качество и оформление кода (читаемость, PEP-8, работа с системой версий) | 10 % |
| Обоснованность выводов (интерпретация счётчиков вызовов и замеров, анализ методом учёта, сравнение с `list`/`deque`) | 10 % |

## Связь с БРС

Итоговый балл за ЛР (0–10) переводится в БРС с коэффициентом 0,6 и суммируется с баллами за остальные ЛР (максимум 48), тестирования (16), дополнительные практические задания (10) и зачёт (30) — см. [`README.md`](../README.md#4-итоговая-оценка).
