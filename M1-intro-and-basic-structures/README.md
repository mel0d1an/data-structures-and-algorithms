# Модуль 1. Введение и базовые структуры

**Раздел 1 РПД.** Лекции 1–2 (4 ч) и лабораторные работы 1–2 (8 ч). Вводит асимптотический анализ (O/Θ/Ω, рекуррентные соотношения), рекурсию, амортизированный анализ и базовые динамические структуры: динамический массив, связные списки, стек и дек.
