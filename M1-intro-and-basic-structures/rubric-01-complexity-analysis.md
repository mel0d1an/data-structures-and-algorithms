# Рубрика-01. ЛР 1 «Анализ временной сложности элементарных алгоритмов»

10-балльная шкала оценивания. Балл рубрики входит в БРС с коэффициентом 0,6 (до 6 баллов за ЛР). Общие правила оценивания — в [`methodical-guidelines/teachers-assessment/`](../methodical-guidelines/teachers-assessment/README.md).

| Уровень | Описание |
| --- | --- |
| **10** | Все четыре алгоритма реализованы корректно; аналитические оценки выведены и обоснованы; замеры выполнены по методике (прогрев, повторы, медиана, log-log); наклоны интерпретированы верно, расхождения объяснены; репрезентативные тесты и инварианты зафиксированы; студент уверенно отвечает на вопросы. |
| **8** | Всё выполнено; мелкие недочёты (например, неполный ряд размеров или неполное объяснение расхождений) студент находит и исправляет сам; объяснение уверенное. |
| **6** | Реализации и замеры в целом верны, но методика соблюдена частично либо аналитические оценки даны без обоснования; объяснение поверхностное. |
| **4** | Часть алгоритмов или замеров отсутствует/неверна; выводы не связаны с данными; работает только по образцу. |
| **0–3** | Код не работает, замеры отсутствуют или студент не может объяснить собственное решение. |

## Критерии (вклад в итоговый балл)

| Критерий | Доля |
| --- | --- |
| Корректность реализации (алгоритмы, прохождение репрезентативных тестов, инварианты) | 35 % |
| Вычислительная эффективность (обоснованность оценок, соответствие замеров асимптотике) | 25 % |
| Полнота верификации (граничные случаи, проверка ИИ-кода по методике при его использовании) | 20 % |
| Качество и оформление кода (читаемость, PEP-8, работа с системой версий) | 10 % |
| Обоснованность выводов (интерпретация графиков, объяснение расхождений) | 10 % |

## Связь с БРС

Итоговый балл за ЛР (0–10) переводится в БРС с коэффициентом 0,6 и суммируется с баллами за остальные ЛР (максимум 48), тестирования (16), дополнительные практические задания (10) и зачёт (30) — см. [`README.md`](../README.md#4-итоговая-оценка).
