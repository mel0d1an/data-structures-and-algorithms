# Рубрика-06. ЛР 6 «Линейный, бинарный и интерполяционный поиск: сравнение»

10-балльная шкала оценивания. Балл рубрики входит в БРС с коэффициентом 0,6 (до 6 баллов за ЛР). Общие правила оценивания — в [`methodical-guidelines/teachers-assessment/`](../methodical-guidelines/teachers-assessment/README.md).

| Уровень | Описание |
| --- | --- |
| **10** | Все три алгоритма корректны, включая инвариант границ бинарного поиска и защиту интерполяционного от равных крайних элементов; счётчики сравнений достоверны; замеры выполнены по методике на обоих распределениях с присутствующими и отсутствующими ключами; графики сравнений и времени построены; вывод о превосходстве интерполяционного поиска на равномерных данных и его деградации на неравномерных обоснован собственными замерами; студент уверенно отвечает на вопросы. |
| **8** | Всё выполнено; мелкие недочёты (например, замеры только по присутствующим ключам или неполное объяснение деградации интерполяционного поиска) студент находит и исправляет сам; объяснение уверенное. |
| **6** | Линейный и бинарный поиск корректны, но интерполяционный работает лишь частично либо методика замеров соблюдена не полностью (одно распределение, нет счётчиков сравнений); сравнение алгоритмов поверхностное, без связи с распределением данных. |
| **4** | Часть алгоритмов не работает или даёт неверные индексы на граничных случаях; сверка с эталоном (`in`/`list.index`/`bisect`) отсутствует; замеры фрагментарны, выводы не связаны с данными. |
| **0–3** | Код не работает, замеры отсутствуют или студент не может объяснить собственное решение. |

## Критерии (вклад в итоговый балл)

| Критерий | Доля |
| --- | --- |
| Корректность реализации (три алгоритма, границы бинарного поиска, счётчики сравнений, граничные случаи) | 35 % |
| Вычислительная эффективность (соответствие замеров оценкам O(n), O(log n), O(log log n) на обоих распределениях) | 25 % |
| Полнота верификации (сверка с эталоном `in`/`list.index`/`bisect`, проверка ИИ-кода по методике при его использовании) | 20 % |
| Качество и оформление кода (читаемость, PEP-8, работа с системой версий) | 10 % |
| Обоснованность выводов (условия превосходства и деградации интерполяционного поиска, интерпретация графиков) | 10 % |

## Связь с БРС

Итоговый балл за ЛР (0–10) переводится в БРС с коэффициентом 0,6 и суммируется с баллами за остальные ЛР (максимум 48), тестирования (16), дополнительные практические задания (10) и зачёт (30) — см. [`README.md`](../README.md#4-итоговая-оценка).
