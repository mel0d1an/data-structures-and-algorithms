# Модуль 4. Алгоритмы поиска и хеш-таблицы

**Раздел 4 РПД.** Лекции 6–8 (6 ч) и лабораторные работы 6–8 (12 ч). Поиск в линейных структурах (линейный, бинарный, интерполяционный), поиск подстрок (КМП, Рабин–Карп, Бойер–Мур), хеш-таблицы (хеш-функции, цепочки, открытая адресация, коэффициент загрузки).

К материалам модуля привязаны все три кейса индустриальных партнёров дисциплины (см. [`Cases/`](../Cases/README.md)).

**Формируемые индикаторы:** ОПК-6.1, ОПК-6.2, ОПК-6.3, ОПК-6.4, ОПК-7.2.
**Контроль раздела:** тест № 4 ([`resources/test-banks/`](../resources/test-banks/README.md)), [ДЗ 3](../Cases/kim-03-astra-log-anomalies.md), [ДЗ 4](../Cases/kim-04-hh-semantic-matching.md).
